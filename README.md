# Connect Counsellor

A dynamic and responsive full-stack web platform that connects users with certified counselors. It allows users to seamlessly book counseling sessions, explore available professionals, and manage their appointments through a user-friendly interface.

## 🛠️ Tech Stack

- **Frontend:** React.js, Tailwind CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Authentication:** JWT
- **Other Tools:** Postman, GitHub, Render

## ✨ Features

- 🧑‍⚕️ **Doctor Profiles:** Explore available counselors with detailed profiles.
- 📅 **Session Booking:** Users can schedule sessions with available doctors.
- 🔒 **User Authentication:** Secure login/signup system using JWT.
- 📂 **User Dashboard:** View booking history and session details.
- 📱 **Responsive Design:** Optimized for all screen sizes.
- 💳 Payment gateway integration

## 🚀 Getting Started

### Prerequisites

- Node.js
- MongoDB

### Setup

```bash
# Clone the repository
git clone https://github.com/rbhavesh1525/Connect-Counsellor

# Install frontend dependencies
cd client
npm install

# Install backend dependencies
cd ../server
npm install

# Run frontend and backend (in separate terminals)
npm start  # for both client and server
